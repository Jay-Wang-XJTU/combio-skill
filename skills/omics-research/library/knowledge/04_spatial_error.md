# 04｜空间上游测量误差及其向下游传播

**错误不只是随机噪声。**空间分割导致邻近细胞转录本混合时，位置和表达会共同受到影响；一条看似合理的通讯边也可能来自共享的上游错误。Proseg论文具体讨论了这类问题及验证代理指标的局限。[G12](../references/GAP_SOURCES.md)

## 1. 建立测量链，而不是只看h5ad

成像式平台：真实转录本 → 探针检测/译码 → 分子坐标 → 细胞边界 → transcript-to-cell归属 → cell×gene矩阵 → 类型/程序 → 邻域图 → niche/通讯/动态。

捕获式平台：组织真实表达 → 扩散/捕获/spot混合 → barcode与count → 背景/组织mask → 反卷积 → 邻域组成与功能。SpotClean针对spot swapping；Baysor/Proseg针对不同的分割问题，不能用一个“去噪”模块无差别代替。[G11–G14](../references/GAP_SOURCES.md)

一个便于推理而非某论文原模型的示意观测式是：

\[
Y_{ig}\sim NB\left(s_i\sum_k A_{ik}\Lambda_{kg}+b_{ig},\phi_g\right),\quad
\tilde r_i=T(r_i)+\eta_i.
\]

这里 `Λ`是真实表达、`A`是分配/混合算子、`s`为捕获、`b`为背景、`T`为坐标变换。明确A按列守恒还是按行混合；坐标误差与A可能依赖，不应默认相互独立。这个模型是S级分析框架，不是声称已估计了所有真实误差。

## 2. 每个平台至少审计哪些字段

成像：原始分子表、译码质量、negative/blank probes、核与膜图像、2D/3D分割版本、边界坐标、未分配分子、极小/极大细胞、merge/split、边缘细胞及分子/细胞计数分布。不同细胞类型的误差可能不对称。

捕获：保留未过滤的背景spot数据和组织mask，记录捕获面积、分辨率、有效库大小、切片厚度、组织外污染梯度与H&E。不要在判断背景污染前就把所有背景spot不可逆删除。SpotClean正文提出其参数估计需要足够背景spot，这个条件不是所有平台通用的固定QC阈值。[G13](../references/GAP_SOURCES.md)

反卷积：参考是否覆盖所有目标类型、细胞类型定义是否匹配、物种/测量平台差异、低丰度类型以及输出到底是丰度、比例还是后验摘要。即使算法输出单细胞级类型信息，Visium spot的反卷积本身也不会创造真实单细胞坐标。cell2location提供的是模型化分解，不能把其输出当成无误差标签。[G14](../references/GAP_SOURCES.md)

坐标：单位μm/pixel、全局/局部FOV、轴方向、z轴、重复cell IDs、组织变形和拼接边界。跨FOV或切片建边前验证是否处于同一坐标系。kNN可能跨越组织裂缝，radius会受细胞密度影响；合理时使用物理距离上限和组织mask。

## 3. 如何建立不循环的验证

人工标注核/膜子集、独立染色、留出未参与分割建模的信号、技术重复或另一测量模态，能够提供不同的检查角度，但各自也不完美。只因为RNA驱动分割后marker更纯，不能就证明边界真实；模型可能在优化同一目标。

检查merge/split、漏检、错分配、未分配、细胞数与形态合理性以及下游读数。不存在一个“聚类更漂亮”足以覆盖所有误差的指标。不同分割输出cell集合不同，要先明确跨分割对应或比较共同组织区域，不能直接把行号当同一细胞。

## 4. 将误差传播到最终研究目标

从上游扰动或后验样本重建counts、注释、图和niche，再重算整合、OT与FM。仅在固定embedding最后加Gaussian噪声不能覆盖分割导致的拓扑变化。建议把固定模型评估与全流程重新拟合分开：前者衡量测量变化对已部署模型的影响，后者衡量研究结论对整个开发流程的依赖。

若只有主观设定的分子错配率、坐标jitter、dropout或基因面板删减，输出是**压力测试范围**。只有从经过校准的测量模型抽样并验证覆盖度，才可以把相应区间解释为概率性不确定性；跨算法分歧不是天然的后验分布。

生物学稳定性指标可包括程序效应方向、界面niche一致性、通讯候选排名、kNN重叠、风险组别变化、OT耦合及FM目的地敏感性。预先定义稳定的是哪个对象；对齐程序语义或组织区域后再比较。

## 5. 本轮运行的实验及不能推出的结论

`lab.spatial`模拟两种细胞状态，肿瘤marker在非肿瘤细胞中真实为0；增加邻居期望count混合与坐标jitter，重建图及niche分数。记录界面细胞的伪marker、边Jaccard和分数漂移。它不是Baysor/Proseg/SpotClean复现，也不是校准的真实污染率估计。

`assignment_mix`是按行的期望表达混合，不进行单分子守恒追踪；实现和输出都明确注明。将来使用分子级数据时应替换成真实assignment重采样，再逐层比较，不能把本toy的混合比例解释为实际平台的误分配率。

## 6. 决策闸门

先做刚体变换/统一单位变换不改变邻域的sanity check；再检查拓扑、表达和类型耦合的误差；最后检验结论是否跨合理上游设置稳健。只有单一分割版本、没有独立图像/分子信息时，应降低精确通讯和罕见混合状态的证据强度，但不因此否定全部空间描述。
