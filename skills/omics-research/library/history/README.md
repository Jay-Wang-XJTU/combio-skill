# 单细胞与空间组学计算方法研究开发：文献驱动 skill 知识底座

**版本：0.1.0 · 日期：2026-09-24 · 状态：研究用草稿，不是已验证自动科研系统。**

本包围绕 Fabian Theis、Dana Pe’er、Zhiyuan Yuan、Luonan Chen、Qinghua Jiang 共同署名的 20 项代表性研究，提取从课题问题定义到模型验证、解释和复现的决策知识。选择以能力覆盖为目标，不是作者排名、完整书目或最新论文综述。CellRank 2 同时关联 Theis 和 Pe’er，只计一次。

## 从这里开始

1. 阅读 [知识总报告](KNOWLEDGE_BASE_ZH.md)。
2. 查看 [文献与阅读覆盖](references/READING_COVERAGE.md)，按需要打开 20 张 `papers/` 证据卡。
3. 通过 [总路由 GUIDE.md](GUIDE.md) 选择相关技能，不要强制串行运行全部 20 个。
4. 复制 `templates/` 中所需模板到具体项目，再填写真实数据与验收阈值。
5. 使用 `evaluations/cases.json` 验证 agent 的研究决策；目前这些测试**未运行**。

## 内容

- `papers/`：20 张来源、事实、输入输出、决策、边界与建议实验的证据卡。
- `skills/`：20 个独立 `GUIDE.md`，含触发、输入、步骤、条件分支、验收、失败处理、产物及来源。
- `references/`：机器可读文献登记、skill 登记及阅读覆盖说明。
- `templates/`：问题卡、主张证据表、数据契约、benchmark 与复现模板。
- `evaluations/`：22 个行为测试案例、未执行状态和结构检查结果。
- `coverage_gaps.md`：未核读/未验证内容与下一轮知识缺口。

## 证据等级

**F：原文事实。** 必须有来源与章节定位，不能用论文的自述性能替代自己的验证。

**S：综合决策规则。** 从不同论文的机制与验证方式抽象得到；具有适用条件，不是普遍定理。

**P：拟开展的测试或建议。** 是本包提出的项目开发步骤，并非声称原作者全部做过这些实验。

定向全文核读 17 项；摘要加官方文档 2 项；摘要加扩展图注 1 项。全部论文都没有在本次运行复现实验，也没有完成逐行源代码与全部补充材料的审计。只做结构检查，不据此宣称科学内容或 agent 行为已经验证。

## 使用约束

本包不复制论文全文、付费附件或第三方源代码。正式使用方法应引用原论文，并遵守其数据与代码许可。各作者是论文共同署名者，不将团队工作全部归因于某一个人。版本号、参数和 API 必须在实际复现时重新核查和固定。

无自动安装或远程执行脚本。文件放入具体 agent 的技能目录前，先核对该 agent 接受的 metadata 格式；本包的 Markdown 工作流可直接作为阅读材料使用。
